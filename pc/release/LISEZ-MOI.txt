LA GARDIENNE — Le sous-sol · L'étage · Dehors
=============================================

JOUER
  Double-clique sur LaGardienne.exe

  Si Windows affiche « Windows a protégé votre ordinateur » :
  clique sur « Informations complémentaires » puis « Exécuter quand même ».
  (Le jeu n'est pas signé numériquement, c'est normal pour un jeu indépendant.)

TROIS CHAPITRES (ils s'enchaînent ; on peut aussi les lancer un par un dans le menu de la télé)
  CHAPITRE 1 — LE SOUS-SOL  le sous-sol (et la garderie derrière la porte au bas de l'escalier).
                            « SANS MONSTRE » : le même, pour visiter tranquille.
  CHAPITRE 2 — L'ÉTAGE .... le rez-de-chaussée de la maison, la nuit. La clé de la porte d'entrée est dans
                            une boîte à trois chiffres sur la cheminée : fouille la cuisine, la salle de bain,
                            sa chambre. Un conseil : ne tourne pas le dos à ce qui se tient sous les draps.
                            Accroupi (C), le plancher ne craque pas. Mets des écouteurs.
  CHAPITRE 3 — DEHORS ..... la cour, dans le brouillard. La grille est fermée par une chaîne.
                            Elle ne te voit pas : elle t'écoute. Marche dans l'herbe, évite le gravier
                            et les feuilles, accroupis-toi. Lance un caillou (G) pour l'envoyer ailleurs.

COMMANDES (clavier + souris, ou manette)
  W A S D / flèches ....... marcher   (Z Q S D sur un clavier AZERTY)
  Souris .................. regarder
  Maj ..................... courir
  C ou Ctrl ............... s'accroupir
  E ou clic gauche ........ interagir / ramasser (garde le bouton enfoncé pour certaines actions)
  F ....................... lampe de poche
  G ou clic droit ......... lancer un caillou (chapitre 3)
  Tab ..................... objectif
  Échap ou P .............. pause / options
  F3 ...................... compteur de performance

  Au centre de l'écran, un petit point blanc : il devient plus lumineux quand tu regardes
  quelque chose qu'on peut ouvrir ou prendre (et l'objet s'éclaire légèrement).
  (Options > INTERFACE : POINT, AUCUNE ou COMPLÈTE.)
  Joue avec un casque pour le son 3D. Chaque bruit peut attirer la Gardienne.

PERFORMANCE
  La qualité est sur AUTO : pendant le chargement, le jeu mesure ta carte graphique et choisit
  le meilleur réglage qu'elle tient sans ralentir.
  F3 affiche le compteur (images/seconde, pire image, temps CPU / GPU, carte graphique, résolution).
  Si ça saccade encore : essaie « LaGardienne - DirectX 12.bat » (souvent plus fluide sur AMD).

PROBLÈMES ?
  - Écran noir ou plantage au démarrage : lance « LaGardienne - DirectX 12.bat »
  - Vieux PC / portable lent : lance « LaGardienne - mode compatibilite.bat »
    (graphismes simplifiés, OpenGL)
  - Tu peux aussi baisser la qualité dans le menu Options (sur la télé).

CONFIGURATION CONSEILLÉE
  Windows 10 ou 11 (64 bits)
  Carte graphique compatible Vulkan ou DirectX 12
  (NVIDIA GTX 1060 ou plus récente, AMD RX 580 ou plus récente ; qualité « Basse » pour les cartes intégrées)

Moteur : Godot 4.5 (Forward+). Textures et modèles 3D : Poly Haven et ambientCG (CC0). Sons : Red Library (CC0).
