# UI fonts (ui module)

Downloaded from Google Fonts (TTF via the fonts.googleapis.com CSS API); licence texts from the matching `@fontsource`
packages. Each folder keeps its licence file next to the fonts. All are free to embed and redistribute with the game.

| `special_elite/` | SpecialElite-Regular | Apache License 2.0 (`LICENSE.txt`) — © 2010 Brian J. Bonislawsky DBA Astigmatic (AOETI) | objective typewriter, padlock drum digits |
| `caveat/` | Caveat-Medium / -Bold | SIL OFL 1.1 (`OFL.txt`) — © 2014 The Caveat Project Authors | handwritten notes, child's crayon drawing, clue scrap |
| `gelasio/` | Gelasio-Regular / -Bold / -Italic | SIL OFL 1.1 (`OFL.txt`) — © 2022 The Gelasio Project Authors | newspaper clipping (Georgia-metric serif) |
