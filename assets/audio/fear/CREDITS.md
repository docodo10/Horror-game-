# Crédits audio — module « fear »

Tous les sons de ce dossier sont **synthétisés de zéro** (aucun enregistrement, aucun échantillon tiers) par
`pc/scripts/fear/tools/make_fear_sounds.py` (Python, numpy + scipy, encodage Ogg Vorbis par ffmpeg/libvorbis).
Licence : **CC0 1.0** (domaine public). Régénération déterministe : `python3 pc/scripts/fear/tools/make_fear_sounds.py`.

| Son | Fichiers | Synthèse |
|---|---|---|
| fear_heartbeat | `fear_heartbeat_1..3.ogg` | « poum-poum » : sinus amortis 37–210 Hz + bruit filtré, saturation douce |
| fear_rumble | `fear_rumble.ogg` (boucle 20 s) | bruit brun < 60 Hz, sinus 31 / 33,5 Hz en battement, grondement 55–150 Hz |
| fear_drone | `fear_drone.ogg` (boucle 30 s, stéréo) | grappe dissonante (secondes mineures, triton), aigus vitreux, souffle |
| fear_tinnitus | `fear_tinnitus_1..2.ogg` | sifflement 6,1 / 4,35 kHz, une oreille plus forte |
| fear_sub_hit | `fear_sub_hit_1..2.ogg` | impact sub-grave (glissando 72 → 27 Hz) |
| fear_stinger | `fear_stinger_1..3.ogg` | crissement de cordes dissonant (scies à vibrato) + réverbération synthétique |
| fear_stinger_big | `fear_stinger_big_1..2.ogg` | grappe cuivres/cordes graves + crissement aigu + boum + crash |
| fear_riser | `fear_riser.ogg` | montée de bruit filtré inversée |
| fear_crash | `fear_crash_1..2.ogg` | synthèse modale : boîte en bois qui tombe, rebonds, petits objets |
| fear_ball | `fear_ball_1..3.ogg` | rebond de balle en caoutchouc |
| fear_distant | `fear_distant_1..3.ogg` | choc / porte / objet traîné au loin, longue queue de réverbération sombre |
| fear_scratch | `fear_scratch_1..2.ogg` | grattement « stick-slip » dans un mur |
